# GeoLocator
Narzędzie w Pythonie do wyszukiwania w OpenStreetMap punktów szczególnych i obiektów geograficznych na terenie całego kraju. Użytkownik wybiera kraj, wprowadza słowo kluczowe lub kategorię, a aplikacja przeszukuje OpenStreetMap za pomocą interfejsu API Overpass i zwraca wszystkie pasujące obiekty.
